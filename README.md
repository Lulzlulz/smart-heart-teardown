# Smart Heart Teardown · The Cardiac Cycle

An interactive 3D left heart you can take apart. Every pressure, volume, valve movement and heart sound is calculated live by a lumped-parameter physiology model (time-varying elastance, Windkessel, simplified Bernoulli valves).

- Presets: normal, aortic stenosis, mitral stenosis, mitral regurgitation, HFrEF, high afterload
- Basic mode for first-years, Advanced mode with PV loop, ECG, PCG and physics sliders
- English · Русский · O'zbekcha (append `#en`, `#ru` or `#uz` to the URL)

Static site: `index.html`, `app.js`, `app.css`. Three.js and fonts load from public CDNs.

Educational simulation — not a medical device and not clinical guidance.
